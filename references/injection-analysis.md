# 注塑专项：CAD 几何、成型风险与关闭证据

## 输入决定结论层级

| 输入 | 可完成 | 不能直接声称 |
|---|---|---|
| 精确 CAD，材料/模具未知 | 局部厚度、筋柱/边缘、假设方向拔模、条件性风险 | 缩痕深度、充填压力、熔接线位置或注塑通过 |
| 正式材料、工艺区域、模具方案 | 定量 DFM、浇口/流长/排气/冷却比较、模流准备 | 求解完成或缺陷消除 |
| 有求解器、牌号与工艺数据 | 范围内 Fill/Pack/Cool/Warp 求解及校验 | 已试模、量产良率或外观批准 |

材料未定仍完成独立的 CAD 工作；依赖材料的建议注明条件。不根据颜色推定硬软胶，也不把一个按键的材料套用到所有结构件。先排除金属、简化占位和未冻结的候选件。

## 可复核的局部厚度测量

1. 选择装配全局精确实体，按面积/位置/风险选面。记录尝试数、有效数、拒绝原因、抽样策略。面抽样不是等面积抽样，不能推算缺陷面积比例。
2. 在面内取点，投影回底层曲面并验证仍在 trimmed face 范围。质心可能落在孔洞/修剪范围外，不能直接用未经检查的质心。
3. 求单位法向，以点内外的小偏移核对材料方向。射线与本实体相交后，取从表面进入材料的首段连续实料。穿空腔后进入第二段材料不能合计成壁厚。
4. 保存起点、方向、边界点、选中区间、搜索长度、容差、面号、单位。搜索窗末端仍在材料内时只报“至少该长度”，不能当准确厚度。
5. 长法向线段可能沿筋长或柱轴穿行。用两个横向截面/线段和原生视图复核，区分细筋与实料厚区。柱轴深度不是柱壁厚；柱壁需在匹配高度做径向测量。
6. 薄区沿切向邻域重采样并投影回曲面，步长按特征尺度选择。毫米级壳体约 ±0.5 mm 仅是一个可选例子。封边/锐边/倒角的极小值不能自动称为主壁缺陷。
7. 关键位置用独立截面/相交复算并回到 CAD 定位。少量样本只称已测局部厚度；全件最薄壁厚必须有全域算法和覆盖证据。

若未检查厚区与薄区的连接，只能说明不同位置厚度不同，不能认定为直接相邻的突变。微小复算差值表示算法一致性，不表示制造精度。

## 筋柱、拔模、包胶

- 筋/柱和各自相邻主壁建立截面后再讨论比例，不能用全件平均/中位壁厚代替根部壁厚。检查掏胶、圆角、交汇堆胶、钢位和顶出支撑。
- 面包围盒沿 Z 的覆盖高度不等于自由悬臂长度，不能据此推定筋的结构/脱模表现。
- 无分型/抽芯输入时明确假设方向。零度平面计数可能包括功能面和侧抽区域，不等于缺陷数量、真实拔模或完整倒扣分析。
- 正式拔模建议依赖树脂、纹理号/深度、筋槽深度、主脱模与侧抽芯；不把通用 1°/2° 或固定筋厚比写成项目强制值。
- 无浇口不能确定流长与汇合位置；无排气图不能认定无排气。深孔/盲柱只提示潜在气体滞留位置。
- 软硬胶结合需核对材料区域/牌号/硬度、相容性、双色/嵌件/二次注塑路线、封胶边、互锁、基材支撑、浇口排气与外观禁区。

## 风险对应的关闭证据

按实际发现选择类别，不凑固定问题数。

| 风险 | CAD 能定位的区域 | 需要的关闭证据 |
|---|---|---|
| 缩痕/空洞 | 厚区、筋柱根、交汇堆胶 | 材料与截面、保压/冷却、试模外观及必要的剖切/CT |
| 翘曲 | 大跨度壳体、不同厚区、装配基准 | 收缩数据、浇口/冷却比较、真实输入的翘曲结果和尺寸样件 |
| 短射/薄边 | 狭窄通路、长薄区、渐薄边 | 流长/压力/剪切结果、分段短射样、材料工艺窗口 |
| 熔接痕 | 孔柱后的潜在汇流区 | 浇口比较、汇合温度/角度/位置、外观和必要的实物强度检查 |
| 困气/烧焦 | 深槽、深柱、末端薄区 | 终填位置叠加排气/镶件图、试模核验 |
| 顶白/拖花/粘模 | 直面、纹理、薄筋、缺支撑处 | 实际抽出方向、纹理/顶出布置、试模脱模与外观 |
| 包胶起边/飞边/脱层 | 封胶边、互锁、薄包胶、基材支撑 | 相容性、工艺路线、封胶结构、实际牌号样件剥离及环境前后检查 |

## 真正运行模流时

确认工具可用、授权范围、算力/费用条件。保存材料流变/PVT/热物性来源、机器限制、浇口流道、填充/保压/冷却参数、网格类型与厚度分辨率、网格质量/敏感性、日志和收敛状态。比较方案固定非比较变量，结果绑定工况和单位。厚度图不叫模流结果，失败工况不出通过结论。

数值规则优先匹配树脂供应商与模具资料。需公共依据时查材料商手册、求解器官方文档等原始来源，记录版本/页码/访问日期；经验值只作筛查，不能代替项目签核。最终明确已测几何、条件风险、未跑求解和待试模证据。
