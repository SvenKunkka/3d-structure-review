# 可选：受力仿真与成品可靠性

仅在用户要求该分支时启用。用户说“跳过受力”“仅注塑”后停止本分支，将已生成资料保留为未纳入本轮交付的中间研究；不让旧范围继续驱动工作。

## 1. 输入不足时如何推进

- 先读取已存在的载荷、环境、任务寿命、材料、接触/紧固和验收要求；只集中提出影响结果的缺口，继续独立的几何提取、选区定位和测试计划。
- 有正式输入：做规定工况分析；输入不完整但可作比较：明确假设、参数范围、敏感性和结论适用范围；无法构造有意义边界：交付分析准备和缺口，不制造彩图作为仿真结果。
- 记录模型来源/哈希、简化内容、孤立件或整机范围、单位体系、材料牌号/温度/应变速率、弹性/塑性模型及数据出处。假设模量不用于实际材料选型或破坏安全系数。
- 先将问题写成可检验目标：某边界下挠度、某接口载荷、某改型相对效果等。不要把“求解成功”作为产品通过标准。

## 2. 建模与边界可视化

1. 按实际承力路径定义约束、载荷和接触；孔附近有螺钉或几何座面，不代表真实预紧连接存在。
2. 使用可追溯的几何选区，保存 CAD 面/坐标/面积与映射。网格实体编号不等于 CAD 面号；重网格后重新投影核验。
3. 约束螺钉环带、轴承区或夹具接触区时显示具体区域，避免整片大面固定抑制弯曲。刚性安装件假设可能降低位移，也可能转移应力，不能笼统称“保守”。
4. 对外表面载荷检查法向、面内外及网格边界归属，避免空间框误选内部筋或重复表面；记录实际受载面积、合力、质心和力矩。
5. 区分法向压力与固定方向面牵引。非均匀网格使用求解器面载荷或形函数一致载荷；不将总力简单均分节点后声称均布压力。
6. 拟合/接触、摩擦、预紧、软胶、间隙、大变形和材料非线性按问题需要建模；省略项需说明物理影响。

## 3. 网格与求解检查

- 记录网格器/求解器版本、单元类型与阶次、节点/单元数、局部尺寸和质量指标；检查连接顺序、非正 Jacobian、退化/极扁单元、自由刚体与不连通区域。
- 将网格体积和关键曲面/薄区回投 CAD，报告体积差及曲面离散误差。二次位移单元的直边中点设置不等于精确曲面几何。
- 先用有解析解的简单梁/板或其他恰当基准检验单位、载荷、边界和输出解释；校准模型不能证明产品边界真实性。
- 对主要指标做网格细化；保持同一连续几何选区及载荷定义，比较位移、反力、远离奇异区的应力/应变。仅两档数值接近时说明“细化后接近”，不自动宣称网格无关。
- 若细化改变载荷面积或质心，报告变化，区分离散边界变化与网格误差；应力未稳定时继续局部细化或限制应力结论。
- 保存完整输入卡、网格、日志、收敛/警告及原始结果；区分计算完成、数值可信和工程适用。

## 4. 独立校核与结果解释

1. 从保存的输入和输出独立计算单位、总载荷、约束/加载集合、合力及关于同一原点的合力矩；检查反力平衡、固定点位移和异常模式。
2. 显示边界条件、变形比例尺及未变形轮廓。分别报告位移、应力/应变、热点位置、网格指标、敏感性和假设。
3. 区分积分点值、节点外推/平滑值、奇异峰值和区域统计；不要任意删去峰值后称应力收敛。固定边、点载荷及接触边的峰值需单独解释。
4. 线弹性零初始状态、比例加载时，`Fᵀu` 是柔度量，弹性应变能为其一半；不要误命名输出字段。
5. 对关键支承/载荷/材料做合理敏感性，检验结论是否随假设改变；模型审计未重算全模型时明确只验证了哪些输入和结果。
6. 静力不代表跌落、冲击、疲劳或蠕变。跌落需质量/惯量、姿态、速度/高度、接触、材料速率特性及动态求解验证；静力等效载荷必须有依据且限定用途。
7. 不用假设树脂与局部孤立壳体结果宣布整机强度合格、寿命达标或开模通过。输出受条件限制的结果和实物关联验证计划。

## 5. 从几何风险建立可靠性计划

- 建立 `需求/风险 ID → 条件 → 失效模式/机理假设 → 后果 → 预防 → 试验/验收` 链条。CAD 交叠/间隙是实测输入，跌落开裂、磨损或断连等是待验证失效假设。
- 根据产品选择相关项目：装配/锁付、挤压/扭转、裸机跌落、运动机构寿命、可拆件保持、接口插拔/侧载、振动/线束、温湿/温变、汗液/清洁剂、包胶/纹理/字符、充电/电气组合状态。
- 将真实配置的模式、附件、左右差异、材料、供应商、温度和使用角点纳入。只检查电子外形时，不声称完成电子功能或认证验证。
- 每个 DVP&R 项填写基线、样品组、夹具/仪器/校准、刺激/环境/工作模式、观测量、限值与来源、时长/次数、检查点、证据、责任和状态。
- 未定载荷、次数、样本量和判据标“待定义/建议”，不将通用数值当本产品强制门槛；可提有依据的候选条件供项目定案。
- 需要引用标准时查官方当前版本、适用范围和项目采用版本；仅读到公开简介时，不声称已按完整标准设计/执行。裸机跌落与包装运输、湿热与防水分别验证。

## 6. 样本、执行与关闭

1. 冻结样品序号、CAD/BOM/PCB/固件、材料/模穴/批次、工艺、装配扭矩及附件；保留未受应力控制样。工程角点样与可靠性代表样分开说明。
2. 先确定失效定义、任务剖面、可靠度目标及置信度，再选择统计方法和样本数。单台循环次数不是独立样品数量；未经验证的加速模型不能换算使用年限。
3. 固定任务寿命、独立同分布样品及零失效方案成立时，可用 `n ≥ ceil(ln(1−C)/ln(R))`，其中 R 为任务存活率、C 为单侧置信度；不满足假设时不用此式，实际失败不得删除或用补样掩盖。
4. 首轮独立应力组利于识别机理；组合试验按使用顺序及已批准计划另建组。记录基线、中间检查、终检及恢复后尺寸/功能，不混算不同版本和不等效变体。
5. 保留原始曲线、实际条件/累计历程、照片、异常录像和拆检证据；安全相关的破坏性实测应由具备设备和规程的人员执行，规划文件不等于已执行。
6. 状态使用未执行、受阻、失败、通过、带偏差通过，并附证据。未执行时不能填零失效或计算通过率；没有评分准则及数据时不编造 FMEA 发生率或 RPN。
7. 修订后按影响范围回归相邻功能、装配、材料/工艺和系统交互；旧版本通过不可自动继承。关闭记录包括根因、改动、重测、残余风险和项目规定的签核。

最终分别说明：已完成的分析、已实际运行的求解、已执行的实物试验、尚缺输入和未检范围。可靠性计划、仿真和供应商自述都不能替代对应样品条件下的真实测试结果。
