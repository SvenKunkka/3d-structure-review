# 本机 CAD 与精确几何证据

## 打开、测量、保存分别验收

1. 查询本机可用 CAD 和当前文档，核实版本及源文件。存在用户未保存文档时，在新文档/独立进程中审阅，不关闭或覆盖它。
2. 原生导入后记录软件、几何内核、选项、单位。用外形包络和已知特征核验比例，不能根据文件名猜毫米。
3. 原生视图证明打开了对应模型；测量日志证明指定计算；保存后回读证明落盘。分别取得证据。
4. 宏、脚本、参数和输出放在当前任务目录，不写死上一次任务的项目、面号或用户名，不覆盖原 CAD。

## FreeCAD 实用路径

FreeCAD 是已使用的精确实体工具，不是唯一选择。

- macOS 常见路径为 `/Applications/FreeCAD.app`，先核实实际安装。`Contents/Resources/bin/python` 与 `Contents/Resources/lib` 可用于原生 FreeCAD/Part/Import；不要跨 Python ABI 混入二进制模块。
- STEP 常用 `Import.insert(path, doc.Name)`，FCStd 用 `App.openDocument(path)`，保存新副本后复开。脚本测量无需每条都 GUI 点击；用户指定本机软件时仍取得原生打开和视图证据。
- GUI 经当前允许的 CAD 接口或电脑控制工具操作，先读工具文档与界面，不盲点菜单或未核实的坐标。
- 首次先做包络、实体清单和单张视图，链路可用再跑大批布尔/截面。崩溃后检查源文件、日志、已输出文件；不重复用已知损坏的恢复件。

## 层级和位姿

记录 Name、Label、TypeId、父子关系、可见性、局部与全局 Placement。父装配聚合 Shape 不与叶节点一起计数；真正的装配实例不能因几何相同被删除。候选姿态和重复占位未确认前分状态评审。

常规导入 Part::Feature 的 Shape 已包含对象局部 Placement 时，复制后补祖先变换的一种已用形式：

```python
s = obj.Shape.copy()
s.Placement = (obj.getGlobalPlacement()
               .multiply(obj.Placement.inverse())
               .multiply(s.Placement))
```

这不是所有 App::Link、Body、实例和导入器的通用配方。先检查对象模型，防止局部位姿重复施加；用 GUI 已知点/包络和一个具有非零父级平移或旋转的零件独立核验。距离、交集、图像和坐标随后使用同一全局形状。

## 算子与含义

- `isValid / isClosed / Solids / Volume / BoundBox` 表示输入健全性和规模，不证明制造合理。
- AABB 重叠只筛候选；精确 `common` 的交集体积/实体才是名义干涉证据。`distToShape` 是指定静态形状的名义距离，不是公差保证。
- 近零结果结合源 CAD 精度、布尔容差、接触意图复核。螺纹、压配、密封压缩等预期重叠单列，不自动判装配失败。
- 面号随版本变化；保存源哈希、对象、面号、坐标和局部图，不直接复用下一版同名面。
- 图可来自原生截图、精确剖切或同一 B-Rep 的投影/离散；离散仅用于可视化时应说明，数值仍以精确几何为准。

最小证据：输入哈希、软件信息、单位坐标、有效性、实际检查范围、局部数据/图像、审阅副本及回读结果。不能将旧项目图片、配置或尺寸当作新项目证据。

## 不同格式的同版本追溯

STEP 与 FCStd/F3D 等原生副本的哈希本来就不同。记录 `源文件哈希 → 导入/转换任务及参数 → 输出文件哈希`，并用实体数量、单位、全局位姿/包络和关键几何的回读建立转换关系；不能要求跨格式哈希相等，也不能仅凭文件名相同认定为同版。两组测量分别绑定不同格式而缺少转换链时，只能核对记录中的数值一致性，不能声称重新验证了当前 CAD。
