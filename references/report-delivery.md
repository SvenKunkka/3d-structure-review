# 报告、关闭清单与验收

## 内容按本轮范围组织

可合并短章节，不固定页数或截图数：

1. 结论和优先动作：证据支持什么、哪些真实缺口影响开模；补充报告注明配套版本。
2. 输入与方法：原图档/哈希、配置版本/单元格、软件、单位坐标、零件/配对/采样覆盖和排除理由。
3. 配置对照：要求原文与位置、对应零件、验证方式、结果和缺口。配置有此功能不等于 CAD 已满足。
4. 选中模块的发现：位置图/剖面、数字/方法、适用条件、影响、建议和关闭证据。
5. 问题清单：编号、优先级依据、位置、实测事实、工程风险、动作、建议责任、关闭证据、状态、修订版和复审栏。
6. 使用边界/来源：已验证、部分完成、未执行、工程依据、待补资料和下一步。

优先级按安全、功能、返工、质量影响和证据评定，不编精确风险概率或 RPN。假设、经验、代理自述与实测分开。

## 数据字段

建议保留以下适用字段；没有面号或法向的检查可省略相应字段，不伪造：

```text
source_hash, model_revision, cad_app_version, units, coordinate_frame
object_id, object_label, assembly_path, instance_state
face_id_1based, point_xyz, direction, method, tolerance, search_extent
value, value_units, uncertainty_or_limit, source_data_path, figure_path
verification_method, verification_result
```

配置记录包括来源 URL/文件、读取时间、文档/工作表、版本、真实行列/单元格、原文、冲突和核对状态。使用 API 返回的行列索引，不手数压缩后的数组位置。证据关联源版本，旧面号不直接用于新模型。

## 图文与排版

- 总装、内侧、剖面、交集和局部放大按解释问题所需选择，保留方向/尺度。图注说明颜色、选中面、变形倍率与假设；几何定位图不伪装成仿真云图。
- 尺寸图来自 CAD，受力图来自真实求解。不能用生成图伪造缺陷结果。
- 可编辑 Word/PDF 使用当前可用文档工具；documents/pdf 技能可辅助，不依赖固定插件缓存版本。
- 文档运行时与 CAD Python 可分开。中文转换缺字时，指定本机可用字体和任务级 fontconfig，不改变全局字体设置。Word 字体名存在不证明 PDF 已正确渲染。
- 转 PDF 后逐页检查中文、表格溢出、图片比例、并排图换行、左右/上下图注、页脚页码、链接和关键数字。
- 自动页码渲染异常先修字段；固定分页报告若用文字页码兜底，核对每页/总页数并说明编辑后需重新分页。

## 最终验收

- CAD 保存副本复开；对象、有效性、全局包络和关键位置可复现。导入副本不等于原参数历史。
- 正文、图注、清单与原始数据的关键数字/面号一致；计数有范围；影响结论的位置独立复核。
- Word 可回读和编辑，PDF 页数正确，所有最终页面已检查。
- 清单逐项对应报告，责任写建议而非假称接单，无试验数据的项目待验证。
- 用输入基线校验源文件；有变化先查明用户修订还是意外改动。哈希只能证明字节一致。
- 任务说明记录范围、完成/未完成、正式位置、复现、缺口和下一步；退出范围的旧中间件保留但不标为当前交付。

最终回复给出可打开的正式路径和影响使用的边界。打开预览、云保存标志、导出对话框、代理完成消息或渲染成功，均不能单独证明整套交付完成。
