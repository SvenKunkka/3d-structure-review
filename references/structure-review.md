# 结构与装配评审

用于已有 STEP/STP 或原生 CAD 的开模前结构检查。按本轮范围选择检查，不要求固定缺陷数量；没有发现问题时写清已检范围即可。注塑细节按主技能指向的注塑模块执行。

## 1. 建立可追溯基线

1. 记录输入文件、大小、SHA-256、修改时间、版本和 CAD 软件/内核版本；只在独立评审目录操作副本。
2. 核对单位、坐标系、上下/左右/前后定义和整机包络。不要从文件名、截图或相似旧型号推断正式版本。
3. 在用户指定的本机 3D 软件打开实际输入，保存整机、主要分件、内部和关键剖面证据；打开成功与几何有效分别记录。
4. 保存原生审阅副本后重新打开；核对导入对象数、实体数、包络及位姿。修复或简化必须另存，并保留前后差异。

## 2. 层级、位姿和几何有效性

- 分别列出装配节点、叶节点、实体和曲面。父级聚合形状与子级同时存在时，不能累计为独立零件。
- 记录每个叶节点的稳定审阅 ID、原名称、标签、父级路径、局部/全局位姿、实体数、体积、面积和全局包围盒；一节点多实体不自动等于多物料。
- 检查空形状、开放壳、无效 B-Rep、零体积及异常远离装配的对象；将失败对象和导入警告单列，不在计数中静默跳过。
- 对嵌套装配先验证坐标变换，再做干涉或尺寸测量。FreeCAD 的变换例子及适用条件见 [native-cad.md](native-cad.md)；用根装配与叶节点包络、选定基准点及 GUI 位置交叉检查。不要再次向已在全局坐标的副本施加变换。
- 按形状、位姿和设计语义区分：同位重复表示、同零件的多个实际实例、机构不同保存状态、备用方案。只对确认的同位重复在分析统计中去重，不删原文件。
- 面号会随重导入/修形改变。每项关键测量同时存对象 ID、全局坐标、面类型/法向、相邻几何特征及输入哈希。

## 3. 功能配置追溯

1. 读取当前正式配置表/BOM/器件图；保留访问时间、版本、表名和单元格坐标。飞书数据用返回的行列索引，不凭数组位置手数。
2. 建立 `需求 ID → 原文与来源 → CAD 对象/接口 → 检查方法 → 证据 → 状态/缺口` 矩阵；“暂定”和冲突规格保留原意。
3. 按功能核对数量、料号/版本、可达性、接口方向、运动模式、可拆件和成套附件。没有在 CAD 中识别出某功能时，写“未能从本模型验证”，不直接判功能缺失。
4. 材料和工艺必须匹配零件/BOM。一类按键的材质不能推广为全部壳体材质；外观颜色不能证明软胶、金属或特定树脂。
5. 将 CAD 可证实的布局/接口与实机触发、触感、磁场、噪声、电气和寿命分开；以指定配置提出验证项，不把配置目标写成已实现功能。

## 4. 静态碰撞和间隙

1. 建立正式装配状态与关键接口列表：壳—壳、壳—支架、PCB—定位/紧固、电池—硬点/线束、连接器—开口、运动件—邻件等；只选本产品相关项。
2. 先用全局包围盒下界筛选，再用精确 B-Rep 最短距离及实体交集检查。候选阈值应来自需检查的间隙/公差预算，记录范围和排除理由，不沿用旧产品常数。
3. 对重叠候选求实体交集并导出定位几何；记录最短点对、交集体积、连通分区和坐标。距离在容差内且交集体积近零时可能为接触/共面；正体积为名义几何重叠，均需核对容差和工程含义。
4. 区分硬干涉、设计预压/紧配、简化器件包络、同位重复和互斥运动状态。明确固定马达筒体与旋转配重等子结构，避免把夹持接触解释为运行碰撞。
5. 包围盒尺寸不是穿透深度；曲面包围盒还可能过估。需要深度时，指定方向或剖面求实际重叠，并保留测量定义。
6. 对关键结论用独立剖切/布尔/重读测量复核，并附局部图。数值精度与内核容差分开，微小交集不能仅凭非零判废。
7. 保存可恢复台账：候选、已完成、失败、未检、去重部件对和状态。缩小检查范围时明确剩余范围，不把候选数或正交集对数称为缺陷数。

## 5. 公差、运动与装配

- 对关键小间隙定义基准、尺寸链、形位、收缩/翘曲、器件最大包络、胶/泡棉及温度/寿命变化；计算最坏组合。统计法仅在分布、独立性和工艺能力有依据时使用。
- 分别给名义间隙、最坏间隙、允许压缩/预压、所需功能余量及数据来源。缺公差时可反算剩余预算并列待补项，不虚构一般公差后宣布通过。
- 建立运动副轴线、自由度、端位、切换状态和限位；检查全行程包络、邻件、线束弯折和装拆路径。离散采样需加密临近接触区并注明未覆盖的连续区间。
- 两个保存姿态不是完整运动验证；静态无重叠不证明运动无卡滞。未定义运动副时先交付状态比对和必要参数，继续不依赖它的几何检查。
- 核对锁付顺序、工具可达、导向、防错、卡扣变形空间、紧固长度、可维修性、装配夹伤和走线应变消除。螺钉 CAD 简化模型不代表扭矩、预紧或防松已验证。
- 电池等软包/弹性件按正式最大包络、膨胀和绝缘设计审查；不要依据刚性名义长方体推断实际可压缩余量。

## 6. 材料、制造与问题关闭

- 核实零件材料牌号、硬度、工艺、表面处理及外观面；围绕实际制造路线检查壁厚/筋柱、圆角、拔模/分型、钢料、加工刀具或装配连接。
- 公开设计指南是筛查依据，不能直接替代材料数据表、正式图纸和供应商能力；数值建议注明适用材料/工艺和来源。
- 每项结论保留：对象与位置、配置关联、测量/观察、工程解释、影响、优先级依据、建议、关闭证据和责任角色。允许“已检未发现问题”。
- 几何已证实、条件风险、信息缺口分别标注。未作全量碰撞、全表面壁厚或全行程扫掠时，不使用“全检通过”。
- 最终核对原始文件哈希，交付已复开的审阅 CAD、测量数据、定位图和报告。开模建议仅覆盖已评审范围；实际放行还需项目规定的公差、材料、模具 DFM 和验证证据。
